# Scientific feedback and contributions

This is Biswajit Jana's discussion demonstration. Corrections are welcome, including evidence that an observing advantage is already understood or negligible.

Identify the claim/equation, explain the issue, cite a primary reference or reproducible counterexample, and distinguish demonstrated corrections from proposed extensions. State units, frame, epoch, timespan and uncertainties for calculations. Synthetic targets are not catalogue stars.

For software defects, give browser/OS, scene, clock, controls, expected/actual behaviour and reproduction steps. Avoid including private information or credentials.

For changes to the model, discuss scope in an issue first. Run `npm ci`, `npm run build`, `npm test`; update assumptions and references. New catalogue inputs need provenance and redistribution terms. Missing radial velocities must not silently become zero. Invented inputs must be labelled.

Rights are described in RIGHTS.md; discussion is not a blanket reuse licence. Published artwork and dependencies retain their own licences. Please keep feedback respectful and focused on evidence.
