# Illustrated report: editable LaTeX source

This is the canonical source of the six-page illustrated report by **Biswajit Jana**, Finding Earth 2.0. It contains native typeset equations, vector quantitative figures, a labelled Galactic reconstruction, a simulation tutorial and linked references. The scientific model remains version 7.4; this is a presentation and documentation upgrade, not a new measurement.

## Build the PDF

Install [Tectonic](https://tectonic-typesetting.github.io/) and Python with `pypdf`, then run from the repository root:

```sh
python report-latex/build_report.py
```

For an executable outside your PATH:

```sh
python report-latex/build_report.py --tectonic /absolute/path/to/tectonic
```

The build was checked with Tectonic 0.17.0. Its first run downloads the required TeX packages and fonts. The script checks the page count, author metadata and extractable text before replacing `output/pdf/Moving_Observer_Illustrated_Report.pdf`. Intermediate files stay in `tmp/latex-report/`.

All figure assets are committed, so editing and compiling the report does not require recomputing the simulation. `main.tex` includes six files in `sections/`; edit these to revise the narrative. The source uses XeTeX/OpenType fonts through Tectonic. A direct `tectonic main.tex` from this folder also compiles it, but does not perform the publishing checks or copy the canonical output.

## Refresh the numerical figures

With the project's Node dependencies and Python packages NumPy, Matplotlib and Pillow installed:

```sh
python report-latex/build_report.py --refresh-figures
```

This runs the existing numerical exports followed by `build_figures.py`. The three chart PDFs contain vector paths and embedded fonts; their plotted values come from the project modules. Refreshing figures does not automatically rewrite numerical claims in the prose: reconcile the text with any changed model results before publication.

## Artwork and provenance

- `images/milky-way.jpg`: ESA/Gaia/DPAC, Stefan Payne-Wardenaar, [2025 reconstruction](https://www.esa.int/ESA_Multimedia/Images/2025/01/The_best_Milky_Way_map_by_Gaia), CC BY-SA 3.0 IGO. The cover adaptation adds vector labels and schematic observer epochs; it is not an external photograph or a prediction of future arm locations. The adapted illustration retains the source's share-alike terms.
- `images/finding-earth-2.png`: the original frozen Finding Earth 2.0 habitability-zone plot, retained with its explanatory caption. See the linked historical repository snapshot in the report and the original provenance records in `report-assets.py`.
- `images/scores.pdf`, `neighbourhood.pdf`, `paths.pdf`: vector plots generated by `build_figures.py` from this project's calculations. They are not browser screenshots or independently observed data.
- The original `discussion-note.pdf` is preserved unchanged in the repository.

Before publishing, render the candidate PDF with Poppler and inspect every page. Check equations, labels, table rules, footers, links and figure captions. The build script's checks do not replace visual review.
